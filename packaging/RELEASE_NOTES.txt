Nova v0.1.0 is the first packaged Windows x64 release.

## 下载与运行

下载 Nova-v0.1.0-windows-x64.zip，完整解压后运行 Nova/Nova.exe。
无需安装 Python；请保留同目录的 _internal 文件夹。
SHA256SUMS.txt 提供 ZIP 的 SHA-256 校验值。

## 主要功能

- 串口文本/HEX 收发、流控配置、循环发送与收发计数。
- Kp/Ki/Kd 独立 2–6 位小数，实时波形、通道筛选、暂停、游标和 CSV 导出。
- 本地高斯过程贝叶斯优化，不需要网络或 API Key。
- Nova v2 自动试验：设备能力检查、命令确认、保护、自动阶跃、最优复测和人工接受/恢复。
- 设备档案、参数方案、只读历史回放与 HTML/CSV/JSON 报告。
- 内置 sim:// 闭环模拟设备；深色/浅色主题和中英文界面。
- 本地规则解释及可选只读云端解释；云端模型不控制设备。

## 验证与边界

- 47 项回归测试通过；Qt 模拟串口完整流程通过。
- ZIP 解压及完整性校验通过；解压后的 Nova.exe 已验证启动、页面导航和 sim:// 遥测接收。
- 支持 Windows x64 便携运行；不包含 Linux/macOS 二进制。
- 本版本未做代码签名，请核对校验值，不要关闭系统安全保护。
- 未完成真实硬件验收和真实云端 API 调用验证。
